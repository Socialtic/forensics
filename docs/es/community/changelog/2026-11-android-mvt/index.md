# [2026-11] Triaje técnico en Android con MVT

## TL;DR

En el mes de noviembre de 2026 publicamos **cuatro nuevos materiales disponibles en Español e Inglés**, todos **relacionados al proceso de triaje técnico de dispositivos Android** utilizando la herramienta MVT. Los materiales buscan **acompañar a lo largo de este proceso**, desde entender conceptos importantes y el funcionamiento de la herramienta, hasta poder interpretar las salidas de la MVT.

## Descripción de los nuevos materiales

En el contexto de este repositorio, definimos el **triaje técnico** como *la revisión acotada y basada en hipótesis de los artefactos del dispositivo que están disponibles (bugreport, extracción de AndroidQF, registros de intrusión, etc.) para identificar [indicadores de compromiso](../../../references/00-glossary/index.md#indicador-de-compromiso-ioc) o [TTP](../../../references/00-glossary/index.md#ttp) que coincidan con vectores de ataque conocidos.*

Para facilitar este proceso de revisión, ponemos a disposición los siguientes nuevos materiales:

| Material | ¿Para qué sirve? |
| ----- | ----- |
| [Explainer: Introducción al triaje técnico de dispositivos Android](../../../explainers/04-explainer-introduction-android-triage/index.md) | **Material de aprendizaje** que explora conceptos y consideraciones importantes al acercarnos a un proceso de triaje, incluyendo la **formulación de hipótesis** y el acercamiento para una **entrevista inicial** con la persona que solicita el apoyo. |
| [Explainer: Explorando la herramienta MVT para el triaje técnico de dispositivos Android](../../../explainers/05-explainer-mvt-android-triage/index.md) | **Material de aprendizaje** que explora el funcionamiento de la **herramienta MVT**, incluyendo los módulos relacionados a Android, y el **modelo mental para hacer un triaje** con esta herramienta. |
| [Tutorial: Uso de MVT para el triaje técnico de dispositivos Android](../../../tutorials/02-tutorial-mvt-android-triage/index.md) | **Material de aprendizaje** con un **ejercicio guiado** a partir de un caso hipotético que utiliza una **extracción de pruebas** generada con la herramienta AndroidQF para llegar a conclusiones iniciales a partir del análisis de la salida de MVT. |
| [How-to: Triaje técnico de dispositivos Android utilizando MVT](../../../how-tos/06-how-to-triage-android-mvt/index.md) | Material para **uso en la atención y ejecución**, que incluye los **comandos** y pasos a seguir para **personas que ya están familiarizadas** con las herramientas. |

## ¿Cómo consultar estos nuevos materiales?

Si es tu primer acercamiento al triaje técnico en Android utilizando MVT, te recomendamos el siguiente orden de lectura:

1. Revisa el [*Explainer: Introducción al triaje técnico de dispositivos Android*](../../../explainers/04-explainer-introduction-android-triage/index.md) para comprender los conceptos clave y el proceso de triaje.
2. Continúa con el [*Explainer: Explorando la herramienta MVT para el triaje técnico de dispositivos Android*](../../../explainers/05-explainer-mvt-android-triage/index.md) para conocer más acerca de la herramienta MVT y su funcionamiento.
3. Pon a prueba los aprendizajes siguiendo el [*Tutorial: Uso de MVT para el triaje técnico de dispositivos Android*](../../../tutorials/02-tutorial-mvt-android-triage/index.md).
4. Guarda el [*How-to: Triaje técnico de dispositivos Android utilizando MVT*](../../../how-tos/06-how-to-triage-android-mvt/index.md) como referencia para futuras atenciones.
